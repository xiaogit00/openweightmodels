# Current UI snapshots — designer handoff

Static HTML captures of the **current** OpenWeightModels interface, for a designer to
redesign from. Open [`index.html`](index.html) first; it links to every screen.

The pages are real renders of the running app, not mockups. Content is deterministic dev
seed data: 16 comparisons, 3 users (`@mira`, `@kev`, `@ana`), fictional model names,
discussion threads and annotations.

## Contents

| File | Screen | State |
| --- | --- | --- |
| `board.html` | Board | Signed in as `@mira`, Live sort, all filters cleared |
| `new-comparison.html` | New comparison | Filled: uploaded base output, 3 challengers, category + effort set |
| `new-comparison-empty.html` | New comparison | First run: empty dropzone and disabled submit |
| `comparison.html` | Comparison | Reading state, annotations off |
| `comparison-annotated.html` | Comparison | Annotation overlay on (6 annotations) |
| `comparison-turns.html` | Comparison (multi-turn) | Two-turn conversation with turn rail |
| `screenshots/*.png` | All of the above | Full-page 1440px screenshots |
| `assets/fonts/` | — | Self-hosted JetBrains Mono and Space Grotesk |

`index.html` and this README are the only hand-written files; everything else is
generated by `scripts/capture-design-pages.mts`.

`comparison-turns.html` is the exception to the seeded bundle: it was captured from a
real two-turn comparison in the local dev database, so its prompts and responses are
longer and more realistic than the terse seed fixtures.

## Sharing

The folder is self-contained — zip it and send it over:

```sh
zip -r openweightmodels-ui-snapshots.zip design_handoff_current
```

Opening `index.html` from disk works in Chrome, Safari and Firefox. No server, build
step or network access is required.

## What is static

- CSS is inlined; fonts are local files.
- All JavaScript is removed. No React, no Next.js runtime, no analytics.
- Form controls are serialised in their captured state (the select, textarea and input
  values are fixed attributes).
- Links between the captured screens work. Other links are pointed at `#` and buttons do
  nothing. Hover, focus, active and responsive styles still behave normally.
- The board's live ticker still scrolls, because it is pure CSS animation.

## Capturing again

The capture script drives Playwright against a dev server with the deterministic seed.
It is intentionally not part of the test suite.

```sh
# One-time: a throwaway database with nothing but the dev seed
createdb openweightmodels_design
DATABASE_URL=postgres://localhost:5432/openweightmodels_design pnpm --filter @owm/core db:migrate
DATABASE_URL=postgres://localhost:5432/openweightmodels_design pnpm --filter @owm/core db:seed

# Terminal 1: app pointed at that database
DATABASE_URL=postgres://localhost:5432/openweightmodels_design \
REDIS_URL=redis://localhost:6379/2 \
  pnpm --filter @owm/web exec next dev -p 3000

# Terminal 2
pnpm exec tsx scripts/capture-design-pages.mts
```

To capture one page without rebuilding the whole bundle — for example a multi-turn
comparison from the dev database — point the same script at an id:

```sh
pnpm exec tsx scripts/capture-design-pages.mts \
  --comparison 01a1869a-4c3b-7086-926d-d6047181a7fe \
  --handle lei --name comparison-turns.html
```

The script writes the HTML files, screenshots and fonts. It does **not** rewrite
`index.html` or this README. Viewport is fixed at 1440×900.

## Layout notes for the designer

- The app is desktop-first and deliberately dense: 12px base type, 10px micro-labels,
  2px radii, 8px card gaps, 20px page gutters.
- Colour, type, spacing and component tokens are described in
  `design_handoff_openweightmodels/README.md` (the original v2 handoff).
- The three core layouts:
  - **Board**: `216px | 1fr` grid; sticky sidebar; card grid
    `repeat(auto-fill, minmax(270px, 1fr))`.
  - **Comparison**: main column `max-width: 1480px`; header and discussion capped at
    860px; response panes `repeat(auto-fit, minmax(380px, 1fr))`.
  - **New comparison**: `1fr | 300px` grid, `max-width: 1120px`; the right column is a
    sticky live card preview.
- The screens are all dark. There is no light theme yet.
