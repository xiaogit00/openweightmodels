# 01: Weight-class catalogue and class browser

**What to build:** The Model registry gains a curated **Weight class** and **Run size** on every open-weight entry, loses the `current`/`previous` release slot, and grows to the catalogue the design assumes — every addition verified against OpenRouter. Step 2 stops being one Open weights list and becomes an **All sizes** tab plus one tab per populated class plus Frontier, with sections, a size glyph, a memory bar on one global log scale, and search that understands class names. Step 1's menu groups by class instead of release.

**Blocked by:** None (can start immediately).
