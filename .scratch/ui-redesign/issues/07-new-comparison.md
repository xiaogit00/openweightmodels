# 07: Redesign New comparison

**What to build:** The redesigned creation form: three step cards, upload and write modes, Turn review with warnings, challenger picker, details, validation, estimate, live Board-card preview, and submit into the Job flow.

**Blocked by:** 02.

**Status:** ready-for-agent.

**Design source:** `design_handoff_redesign/designs/New Comparison.dc.html` and the "Screen 2 — New comparison" section of `design_handoff_redesign/README.md`, with the deliberate exception in decision 3.

- [ ] Layout: wrapping flex, max-width 1200px, padding 40px 32px 80px, 40/48px gap. Form flex `999 1 520px`. Aside flex `1 1 280px`, max 360px, sticky at `top: 93px`, drops under the form on narrow screens.
- [ ] Intro: H1 30px "New comparison" and the 14.5px subtitle from the design, max 600px.
- [ ] Three step cards: `--color-bg`, 1px `neutral-700`, `--r-lg`, 24px padding, 20px gap. Header: 26px number marker that becomes an accent check when complete; 18px heading. Completion: Step 1 = file + generated-by + prompt (upload) or prompt + base model + **Base reply** (write); Step 2 = ≥1 model; Step 3 = title + ≥1 category.
- [ ] **Step 1 modes:** segmented **Upload a conversation** / **Write a prompt**.
- [ ] **Upload, empty:** full-width dashed dropzone (1.5px `neutral-600`, surface, 40px padding), upload icon, "Drop a .md file, or **browse**", helper about AI Exporter / front-matter / plain markdown, accent drag state. Click opens the hidden `.md,.markdown,.txt` input. **How to get this file** panel with the three numbered steps, Chrome Web Store link, "Download a sample export" (downloads `/samples/deepseek-export.md` in production, not a form fill) and "Read the export guide".
- [ ] **Upload, with file:** file row with 36px file tile, name, `size · lines · turns`, outlined **Replace**; two-column field grid with **Generated by** listbox (initials, name, caret; grouped OPEN WEIGHTS · CURRENT / PREVIOUS and FRONTIER API · CURRENT / PREVIOUS, previous suffixed "(previous)", accent check on selected) and **Prompt · from front-matter** textarea (2 rows, maxlength 10000).
- [ ] **Turn review:** up to 6 Turn cards with TURN n, the Prompt as a right-aligned bubble, and Reply clamped to 3 lines. **Keep the current warnings and errors**: truncated final reply warning, merged-adjacent-user-message notes, missing reply, unrecognised sections, raw chat paste, empty body and oversized file. Blocking errors stay specific and block scheduling.
- [ ] **Write mode:** Base model listbox (same component), Prompt textarea (5 rows, placeholder "Write the prompt every model will answer…", 10,000 counter), **and the existing Base reply field** ("Paste what the base model wrote…"). The platform does not generate the Base output. Completion requires all three.
- [ ] Estimate and limits: "N turns × M models = K calls · ~T input tokens per model" once a Base and ≥1 model exist; "Up to 6 turns · 0.5 MB file · 100,000 characters".
- [ ] **Step 2:** header "N of 4 selected"; 40px model search with visually hidden label "Search models"; weights segmented All / Open weights / Frontier API; selected chips (initials, name, ×; removing deselects); sections OPEN WEIGHTS, FRONTIER API and previous-release sections; 56px+ cards with 28px tile, name, "Open weights · ~6s", 18px check; selected accent state; unselected disabled at 4 with opacity .45; "No models match “q”."; **Show/Hide previous releases**. Keep max 4 and every `data-model-section`, `data-model-weight`, `data-previous-badge`, `data-selected-models` hook.
- [ ] **Step 3:** title input 42px, maxlength 200, counter, auto-filled from the Prompt until `titleTouched`; category chips; effort cards with glyph, label and description (Low — Quick prompt, Med — Multi-step, High — Hard / long).
- [ ] **Submit:** 42px accent **Schedule comparison** with paper-plane icon; disabled state `neutral-800` / `neutral-400` / `not-allowed` and the existing hint list, extended with "Paste what the base model wrote to continue" for write mode. Ready hint is turns × models calls plus the slowest model's ETA (no +1 in write mode). Submitting shows spinner + "Scheduling…" and navigates to `/comparisons/{id}/job`, **not** straight to the comparison.
- [ ] **Aside:** the exact Board card fed from the form — first category or muted placeholder, effort, Turn count, title or placeholder, Base badge/name and excerpt (upload reply or pasted Base reply), first Challenger + "+N more", "Generated after scheduling" for the Challenger preview, `@handle · Draft` footer with dot, caption below. Sticky and hidden behind the form on narrow screens per the design.
- [ ] Preserve the upload parser, limits, seed-model picker, keyboard navigation and error copy. No generated Base output.
- [ ] Both themes. Update `e2e/visual.spec.ts` New comparison metrics to max-width 1200px and the new two-column flex measurement (the old grid-column assertion no longer applies); refresh the dark baseline and add a light baseline.
- [ ] `pnpm typecheck`, `pnpm test`, `pnpm test:e2e` pass, including `import-conversation.spec.ts`, `model-pickers.spec.ts`, `journey.spec.ts`, `responsive.spec.ts`, `keyboard.spec.ts`.

**Key files:** `apps/web/src/app/new/page.tsx`, `apps/web/src/components/new-comparison-client.tsx`, `comparison-preview.tsx`, `how-to-get-this-file.tsx`, `e2e/visual.spec.ts`, `e2e/import-conversation.spec.ts`, `e2e/model-pickers.spec.ts`.

The design's fake 3.6s generation and local sample-fill are prototype behaviour, not requirements. The live preview must use the same card component as the Board (ticket 03) rather than a copy.
